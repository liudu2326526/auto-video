1. 文件菜单新建草稿，原工程自动保存，命名`auto-video-edit-smoke-v1`。
2. 导入程序按源帧[30,210)、[330,510)准备的两段6秒视频。素材卡片预览/初次拖放未立即给出可靠落轨反馈；通过素材右键“根据选中素材新建时间线”，复制片段到主时间线02，End定位6秒后粘贴第二段，实际总长12秒。这里只验证程序选段+剪映编排，不称为剪映原生源区间裁切。
3. 导入`narration.wav`，通过原生时间线复制与Home定位粘贴，独立音轨从0到12秒。GUI检查仅此一条旁白轨，0dB音量。
4. 从“字幕→新建字幕→导入本地字幕”导入SRT。最终核对实际字幕轨只有两段：0..6秒“这是剪辑测试，先看第一段。”，6..12秒“再看第二段，字幕配音都要保留。”。试验中产生的多余手动文字/空白层已在本测试工程移除。不能把“正在预览—文本”当作字幕已落轨。
5. 从普通“叠化”卡片的可见+按钮应用到接缝。剪映提示边缘长度不足、将补重复帧以不改变片段时长。实际转场参数显示“叠化/0.5s”，总长仍12秒。
6. 剪映原生导出：确认主时间线02、原始1280×720、30fps、MP4；额外MP3与云备份关闭。点击导出后先见“正在导出”，后见“导出成功”。关闭完成页，没有点击发布/分享。
7. 按快捷键页面实际显示的Cmd-Option-Q返回首页；首页出现本项目12秒草稿卡。复制准确原生目录作备份后，重新打开同名卡。实际轨道、字幕、配音、转场和12秒总长均保留，无丢失素材提示；选中重开的转场再次显示0.5s。
