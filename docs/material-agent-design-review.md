# 素材 Agent 设计来源与实施审核

用户要求方案设计优先使用 Claude Code，由 Codex review 并实施。本次实际调用本机 Claude Code 2.1.310，
关闭其所有工具和 MCP，仅请求只读方案。第一轮因 API DNS/网络不可达退出；恢复受控网络访问后第二轮
成功退出 0，返回方案。没有让 Claude 修改项目、执行命令、下载素材或访问用户数据。
原始方案保存在 [Claude 提案](material-agent-claude-proposal.md)；它是提案，不代表功能已经完成。

Codex 在请求等待期间准备隔离框架，收到方案后审核并完成实现。采用：

- 操作者公开检索/导入作为 MVP，不假设搜索/下载平台 API 可用。
- 文件内容寻址去重，授权依据单独、不可覆盖；不同来源不得合并成更宽松权限。
- 统一 eligibility 闸门，文件哈希、元数据摘要、精确用途与期限共同约束审核和复用。
- 明确 human/agent 审核种类；批准只接受实际 human 声明，单机记录不等于身份认证。
- 结构化商用、修改、分发场景、相同方式共享、许可失效时间；未知义务不能默认已处理。
- handoff 形成可核验的包，verify 在剪辑前重查当时许可与人工审核、所有文件和署名清单哈希。
- 按现有编剧/剪辑字段导出，图片和非 CFR 30fps 素材另列处理需求；不隐式转码或伪造实测。

缩减与未采用：

- 采用一个独立 material_agent 包和 SQLite，不实现提案中的多层服务、插件、云索引、变体继承与全部 CLI 名称。
- 显式 public_nonpersonal 与独立公开关键词是实际边界；不声称 PII 正则可以保证脱敏。
- 不实现源码内许可注册表，不把许可证名称映射自动当成已获准；具体素材页、条款和人工审核仍必需。
- 不采纳“任何字节改变都必然是法律上的衍生作品”的概括；本项目剪辑用途保守申明 derivatives=true，
  具体法律适用不由程序裁决。
- 授权证据目前保存 URL、时间及操作员摘要，不冒充网页快照或独立验证过的第三方签名。
  自动抓取/网页变化监控/到期后历史补录留待后续需求。
- 不因 helper 成功就认定工程/成片完成；仍需剪辑的源帧校验、实际素材观察和最终视听审核。

独立只读代码审核发现并修复：审核时间可早于下载/入库、无检索命中时漏验用途。
回归要求审核不早于本地文件与记录取得；历史时点不能把尚未入库的文件视为可用。
专项测试另验证直接 SQL 修改/删除记录被拒、精确授权用途、过期、拒绝优先、原文件保留和交付篡改。
用合成 CFR 30fps 视频真实运行 ffprobe，并将导出 asset 映射交由现有 editing_agent.validate 校验。
语音可用性在这项合同测试里模拟，不启动 TTS 或 GUI；没有声称剪映原生剪辑通过。

实际公开检索由协作研究岗位核查单个 Wikimedia Commons 图片与 Creative Commons 官方条款，
保留在 fixtures/materials/commons-laptop.json；仅元数据候选，未下载、未视觉审核或实际使用。
本次不修改编剧/剪辑共享源码，不提交二进制/SQLite，不推送，交统筹统一处理分支集成。
