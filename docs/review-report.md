## 2. 主要发现与修订

| 等级 | 初稿问题 | 修订方向 |

| P1 | TTY 与重输 ID 被当成人类身份，Agent 可伪造 PTY | 独立可信审批身份/入口；审批绑定不可变完整发布包及目标，Agent 无法自批 |
| P1 | 允许对账后新尝试，同时承诺整个计划最多提交一次 | 每个发送许可原子消费一次；UNKNOWN 禁盲重提；跨系统不承诺 exactly-once 或绝对不重复 |
| P1 | 先哈希再 rename Agent 可写源文件存在 TOCTOU/打开句柄修改 | 协调器私有 staging、受控 fd 复制和哈希复核、路径/软链约束、原子发布 |
| P1 | p50 预留冒充硬预算，重复释放可被其他预留掩盖 | 独立 reservation、幂等结算、UNKNOWN 保留额度；硬限额与软预算分开 |
| P1 | SQL 示例缺失关联表、成功状态冗余、同日复测限制 | 补齐/复核表及约束、统一成功含义、允许新 run 复测；执行内存 SQLite 验证 |
| P1 | 认为隔离 shell 就能消除注入风险 | 网关校验任务/动作/目标范围；保留语义风险和高影响动作审批；撤销先阻断旧请求及在途动作 |
| P1 | 删 var 或仅凭媒体对象恢复数据库/发布记录 | 在测试副本只删派生缓存；恢复依赖一致性 DB 备份、对象清单、journal 与发布历史，未知操作先对账 |
| P1 | 隔离等关键项失败但记录后仍可声明首版可用 | 对应自动化硬阻断，人工监督替代单独验收，不降低保证后仍宣称通过 |
| P2 | FFmpeg/manual publish 被误标成 README 已知硬约束 | 标为新增设计决定；不将设计选型当成实现能力 |
| P2 | 要求跨环境同一视频哈希、98% 审看算完整 | 区分字节确定性与媒体等价；要求全片区间覆盖，不以抽帧/转写替代看听 |
| P2 | MVP 投入、音频、剪辑单不够明确 | 增加纵向样片探针、手工合规旁白起步、剪辑单契约；明确粗估与待决策 |
