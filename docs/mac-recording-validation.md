# Mac 录屏工程验证记录

日期：2026-11-02 UTC。记录作者：Codex 本机执行者。**本文是按真实证据整理的工程记录，不是 Claude 设计产物，也不是完整实测 Agent 验收。**

## 1. 范围与源码来源

本轮目标是验证当前 Mac 能否只录一个无敏感内容的自建窗口，且不开麦克风或摄像头。没有再次录制，也没有测试真实第三方产品功能。

探针由 Codex 在本机编写并临时编译；可复现的非秘密附件位于 [examples/mac-recording-probe](../examples/mac-recording-probe/README.md)。它不是产品录屏服务、桌面网关或已通过隔离验收的 Agent。

原片、抽帧、事件、ffprobe 输出、解码日志均保存在本机仓库之外；本记录不包含个人目录、认证值或原始运行日志。没有把原片或抽帧发送到模型服务。

## 3. 权限与执行上下文

初始受限终端中，`CGPreflightScreenCaptureAccess=False`、`AXIsProcessTrusted=False`。随后获准的本机执行上下文、录屏探针自身及最终重连复检中，两项均为 **True**。

这些结果只代表各自当时的执行上下文，不能推广到其他应用或未来进程。已调用官方屏幕录制权限请求接口，因该上下文已有授权而返回 True；辅助功能预检 True，未重复申请。没有出现新的系统授权弹窗，因此没有可报告的提示应用名，也没有待用户点击的授权步骤。

本次自己窗口的录屏不依赖 AX 模拟输入；AX 为诊断预检，不代表实际键鼠自动化已通过。系统声音、麦克风、摄像头分别验收，本次后两项禁止启用。

## 4. 实际执行与选源

执行时间为 2026-11-02T13:56:10Z 至 13:56:19Z，探针进程正常退出码 **0**，总运行约 **9.372 秒**。

1. 创建只显示固定测试文字、动画计数和移动色块的 NSWindow。
2. `SCShareableContent.getCurrentProcessShareableContent` 只枚举探针进程窗口。
3. 校验窗口 ID 与 owner PID，使用 `SCContentFilter(desktopIndependentWindow:)` 选择单一自建窗口；没有显示器或矩形录制回退。
4. 设置 `capturesAudio=false`、`captureMicrophone=false`，没有摄像头调用。
5. 收到实际 start、stop、finish 回调；前台/窗口可见性监视器未报告干扰。
6. 完成后检查最终文件元数据、完整解码及三张抽帧。

此过程证明一次自建窗口无声捕获可用；没有做刻意遮挡、权限中途撤销、多屏切换或其他应用敏感窗口挑战，不能推广为这些场景已通过。

## 6. 抽帧与检查边界

1、3、6 秒抽帧在本机 Apple Vision 离线识别，均匹配自建窗口预期文字；未预期文字计数均为 0。动画计数分别为 **36、66、111**，三帧哈希不同。第一次受限上下文的本机文字检查失败，随后获准的本机上下文检查成功；失败没有计作通过。

以上抽帧检查不代替整片逐帧人工审看；完整解码只证明媒体可解码，不证明所有画面语义或真实工具功能正确。无声任务无音轨符合本轮目标，但不算系统声音验收。
