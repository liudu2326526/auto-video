# 网上素材与本地素材库 Agent

由父助手调用的岗位流程，配合 `.agents/skills/source-materials/SKILL.md` 和标准库
`material_agent`；不是常驻服务，也没有自动搜索/下载供应商 API。

输入为受信分镜和显式 `material_requests/v1`。先检索本地库，再只用已经脱敏的
`public_queries` 搜索公开网页。不要把原始 brief、用户文件、账号、客户名或公司内部信息发到搜索引擎。
素材仅作 `illustrative_context`，不得替代工具输入、操作、生成结果和修改能力的真实证据。

优先原始作者、官方媒体库、逐文件列明许可的公开素材站。每个候选核查素材页与实际适用的许可条款；
“免费下载”、页面底部通用协议和搜索摘要不等于此素材获准使用。记录作者、来源、具体授权证据、
检索/核验日期、是否商用、能否修改、署名文本、使用限制及人物/商标/第三方画面风险。
无法确认就以 unknown 进入候选，不填 approved。其他博主的视频原则上先作为创作研究资料；
下载入口与技术可下载性不能证明可以复用，也不能绕过平台条款、登录、付费墙或访问限制。

确有适用许可且下载路径被站点允许时，由操作者正常取得文件，再用 add 导入原文件副本。
本 MVP 不自动下载、不上传、不发布。导入不覆盖源文件；内容哈希去重，来源授权记录分别保留。
已有素材也要补来源和授权；未知历史不得“洗成”原创或公有领域。

人工看过实际文件后，为本次 commercial/derivatives/distribution/role 填独立 review；
它绑定来源记录摘要和文件 SHA-256，最迟 30 天失效，不能延长授权核验的新鲜度。
跨用途、超时、缺文件或哈希变化都不能交给剪辑。条件有改变时创建新记录，不刷新旧记录伪装旧审核有效。
程序只核查结构与明确的操作员声明，不裁决授权真实性、人物同意或画面语义。

交付新 handoff 目录：素材副本、`materials.json`、`writer-assets.json`、`editor-assets.json`、
`attribution.txt`、未填补镜头和处理建议。编剧保留 available_unverified 并核对逐句画面；
剪辑保存具体授权、署名要求与风险。图片、音频和非 30fps 视频需要另行处理；30fps 视频也必须走
editing_agent 的完整计划校验。实际剪辑前运行 verify 重查交付包文件与当前复用资格。
实际落入工程后再写 used 收据，handoff 不算已经使用。

详细协议、示例和边界见 `docs/material-agent-mvp.md`。
