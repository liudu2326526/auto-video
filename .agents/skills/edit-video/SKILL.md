# Mac 剪映剪辑

在仓库根目录运行 `python3 -m editing_agent --help`。输入协议和边界见
[实施说明](../../../docs/editing-agent-mvp.md)，完整安全例子由 `examples/make_editing_fixture.py` 生成。
本机剪映11.7的实际路径和已验证操作见[实机记录](../../../docs/editing-agent-jianying-validation.md)；遇到同版界面时读取该记录。

1. 读取冻结脚本、分镜、录屏可用区间及真实耗时/限制，整理 `jianying_edit_plan/v1`。先 validate，再 prepare 到新的 attempt。保留源文件和已有工程。程序只准备选段、SRT 和旁白，不能声称剪映已完成编辑。
2. 通过统筹取得同一台 Mac 的桌面时段。先用 `cua_repl` 观察当前工程；`cua.getApp('com.lemon.lvpro')` 若返回多个安装身份，使用工具实际列出的主应用完整路径选择，不猜测或修改安装。本机实际路径为 `/Applications/VideoFusion-macOS.app`，显示剪映专业版11.7。新建本任务工程，不修改其他项目。所有 UI 输入只使用该工具；每批输入后重新观察。
3. 读取 attempt 的 `import_package.json`。在剪映按清单导入视频和 narration.wav，把片段按序放入主轨，旁白放独立音轨，从零开始。检查整条时间轴帧数。原声预剪素材为静音。
4. 导入 subtitles.srt，检查两端时间、中文文本和安全区；使用可用的普通字幕样式。亮色画面使用白字黑描边或有实测对比的底色，分别检查各句及亮色背景；不能仅看深色预览。本机11.7的普通白字黑描边预设已实测，可在文本基础面板勾选“应用到全部字幕”后应用；随后逐句核对文本和时序未变。卡片预览成功不表示已经落轨；须在实际时间线上确认各字幕片段。按计划在接缝添加原生叠化，核对转场时长和总时长。边缘不足而补重复帧的提示要记入结果。免费素材不足时报告具体缺项；不购买或换成未要求的效果。
5. 用独立 JSON 收据记录实际看到的 checkpoint，运行 event 写入事件日志。收据 `event/app/project_name/observed/details` 写事实；导出事件再含 `export_path`，重开事件含 `project_path`。不能预写“通过”。
6. 导出前确认准确目标、分辨率、30fps和本次工程身份，保存 export_requested 收据，再点击剪映导出。若超时，先对账进度和文件，状态不明记 export_unknown，不盲目重导出。结果确认后记录新的 export_completed；needs_input 阻塞处理后用 blocker_resolved 事实收据解除。
7. 保存工程，离开后重新打开，确认轨道、字幕、转场、配音和素材仍在。重开后重新读取准确草稿路径：本机文件夹在退出到首页时才从默认日期名改成工程名。仅保存本任务原生目录副本，不搜索或复制无关工程；保留素材引用，不能假定原生目录内嵌全部源素材。记录 project_reopened。
8. 完整查看成片和审听配音后，才记录 visual_review_passed/audio_review_passed。全帧联系表、静帧检查、波形相关或ASR不能替代连续观看和实际听审；没有可听反馈时明确记录未听审，不填通过。运行 verify 检查工程文件、尺寸、帧率、准确帧数、音轨、非静音与全解码。缺项保持 partial，向下游交付具体问题与恢复点。修改成片时先复制本任务原生草稿并使用新attempt/新导出，保留旧成片、闭合工程快照及素材；用哈希核实旧版本未被更改。

GUI 证据是实际观察记录；CLI 无法自动证明字幕语义、配音内容或转场正确。
当前支持固定30fps、等速单视频轨、居中 contain、一旁白轨和接缝叠化；其他参数由校验器拒绝。
交付原生工程和导出视频准确位置、素材引用、计划、收据与 verification.json，并区分程序选段与剪映原生操作。
