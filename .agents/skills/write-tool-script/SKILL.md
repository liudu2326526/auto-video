# Write a tool-video script

Work from the repository root. Read `agents/scriptwriter.md` and `docs/scriptwriter-mvp.md`. This is an assistant-operated writer skill plus a deterministic Python helper, not an automatic LLM service. The assistant creates the creative draft; the helper validates references and exports it.

1. Read a single candidate from discovery `candidates.json`. Do not change its status, gates or `capability_tested` to make a story pass. Distinguish page observations from actual product use.
2. Read the trusted user/parent brief. Choose a concrete audience, pain point, hook and payoff. Prepare only fictional nonpersonal demo input in this MVP.
3. Create a draft following `fixtures/scriptwriter/gamma-draft.json`. Set `candidate_digest` with `scriptwriter_agent.core.digest(candidate)`; do not simply refresh this digest after a candidate change without rechecking every source reference. Source IDs are `source_001`, `source_002`, etc., in candidate fact order.
4. For new tool tests, use explicit `schema_version=2` and the [task/result contract](../../../docs/scriptwriter-task-result-v2.md). Start with an actual result, then one concrete task, real input, key action, visible change, actual limitation and suitable audience. The 45–55-second rhythm is a suggestion only when the footage supports it. Prepare2–3distinct hooks and choose one. Each scene needs goal/hook/visible_change/emotion/transition_purpose/fallback and per-line narration/subtitle/time/evidence bindings. A small relatable observation is enough; do not invent a failure, reaction, speed or success for comedy. If untested, mark each corresponding line missing and write proposed capture steps, never final assertions.
5. Execute the local helper, using a new ignored output directory:

```sh
python -m scriptwriter_agent \
  --candidates var/discovery/runs/<run-id>/candidates.json \
  --tool-id <tool-id> --draft <trusted-draft.json> \
  --output var/scriptwriter/<new-attempt>
```

6. Read the exported review, warnings and all scenes. Correct evidence semantics, attribution and narrative pacing yourself; regex is only a guardrail. Rehearse narration rather than treating character count as measured duration.

   For v2, supply `--media-catalog <catalog.json> --evidence-root <directory>`. The catalog contains operator-observed local video identities, hashes and millisecond ranges; inspect the actual footage before annotating it. A `screen_result` slide preview cannot stand in for `tool_input`, `tool_action`, `tool_change` or `tool_verification`, even if the narration is called an opinion. `tool_*` segments also reference independent test observations; annotated video and test claims still require semantic review. Narration/subtitle lines cover each scene exactly and refer to contained source ranges, not arbitrary screenshot names. Source evidence milliseconds are not measured generation elapsed time, and are not an automatically executable edit timeline.

   Read `material-gaps.md` and `story_readiness`. `needs_materials` blocks freezing the edit: transfer actual existing footage, separately authorize/perform capture, rewrite or omit the missing shot. Do not fill45seconds with unrelated page turns or silently relabel a task test as a preview. `evidence_linked_requires_review` only means the local structure/bytes/ranges were checked; rights, privacy, meaning, actual audio and exported media remain pending. V1 remains `legacy_unassessed`, never implicitly editing-ready. Hand off exact confirmed ranges to editing_agent's separate frame-based contract; no automatic adapter is implemented.
7. After separately authorized real testing, use `--test-report <report.json> --evidence-root <directory>` to validate local evidence. Record failed outcomes as well as successes. Do not call page observations test results. Keep each revision in a new output directory.
8. Return script, storyboard, asset list, recording plan, known blockers and review status. No file generated by this helper grants browser, account, purchase, recording or publication authority. No `--final` or approval mode exists in this MVP.
